Welcome! Three steps to get going

  1. Connect the robot — enter its IP address (shown on its display) or pick it over USB.
  2. Allow access — Firefox asks once whether the extension may talk to that address.
  3. Open ChatGPT, Claude or Open WebUI and send a prompt. The robot thinks, types and rings when it's done.

Robot connection

How the extension reaches your Tiny Engineer.

Wi-Fi traffic to the robot is plain HTTP and not encrypted; the token is stored unencrypted in this Firefox profile.

Web Serial isn't available in this Firefox, so USB can't be used here. Please use Wi-Fi.

Plug the robot in by USB and choose its serial port. Close other programs that use the port first (e.g. tiny-engineer daemon release). USB has no token — physical access is enough to control the robot.
