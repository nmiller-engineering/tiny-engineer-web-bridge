Robot connection

Connect via

Web Serial is not available in this Firefox version or profile, so the USB connection cannot be used here. Use Wi-Fi instead, or see the README section “USB / Web Serial”.

Connect the robot by USB and choose its serial port. Close other programs using the port first (for example run tiny-engineer daemon release). The serial protocol has no token: anyone with physical access can control the robot.

Communication with the robot is plain HTTP on your local network and is not encrypted. The token is stored unencrypted in this Firefox profile. See SECURITY.md.
